# Vườn hoa 20/10

Website tĩnh tương tác dành tặng các bạn nữ trong lớp. Chạy được trên GitHub Pages, Cloudflare Pages, Netlify hoặc bất kỳ static host nào.

## Chạy thử

Mở terminal tại thư mục dự án và chạy:

```powershell
python -m http.server 8080 --directory dist
```

Sau đó mở `http://localhost:8080`.

## Thay ảnh, nội dung, con trỏ và nhạc

Mọi thứ cần sửa nằm trong `dist/config.js`:

- Chép ảnh vào `dist/assets/photos/` và đặt tên `photo-01.jpg` đến `photo-04.jpg`, hoặc đổi đường dẫn trong `photos`.
- Sửa `className`, lời nhắn từng ảnh và `finalWish`.
- Con trỏ mặc định là emoji. Muốn dùng ảnh riêng, chép ảnh PNG nền trong suốt vào `dist/assets/cursor.png`, rồi đặt `cursorImage: "assets/cursor.png"`.
- Muốn có nhạc nền, chép file MP3 vào `dist/assets/music.mp3`. Nên dùng file nhỏ hơn 3 MB. Nếu file có tên khác, sửa `musicFile` trong `dist/config.js`, ví dụ `musicFile: "assets/nhac-20-10.mp3"`.

## Bật bảng hoa chung cho mọi thiết bị

Nếu chưa cấu hình, các bó hoa vẫn được lưu bằng `localStorage`, phù hợp để chạy thử nhưng chỉ thấy trên cùng một trình duyệt.

Để cả lớp cùng thấy bảng hoa, tạo một dự án Supabase miễn phí, mở SQL Editor và chạy:

```sql
create table public.bouquets (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 30),
  flowers text not null check (char_length(flowers) between 3 and 60),
  created_at timestamptz not null default now()
);

alter table public.bouquets enable row level security;

create policy "Public can read bouquets"
on public.bouquets for select to anon using (true);

create policy "Public can add bouquets"
on public.bouquets for insert to anon with check (
  char_length(name) between 1 and 30
  and char_length(flowers) between 3 and 60
);
```

Trong Supabase, lấy Project URL và anon public key ở **Project Settings → API**, rồi điền vào `supabaseUrl` và `supabaseAnonKey` trong `dist/config.js`. Chỉ dùng **anon key**, tuyệt đối không đưa service-role key lên web.

## Đăng GitHub Pages

Đẩy thư mục dự án lên GitHub. Trong **Settings → Pages**, chọn **Deploy from a branch**, chọn branch `main` và thư mục `/docs`; nếu muốn dùng cách này, đổi tên thư mục `dist` thành `docs`. Hoặc dùng GitHub Actions/static host và chọn `dist` làm publish directory.
